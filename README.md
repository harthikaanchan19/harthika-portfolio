A clean, modern, and minimal personal portfolio website designed from scratch with pure **HTML5**, **CSS3**, and **Vanilla JavaScript** (zero external frameworks—no React, Vite, Tailwind CSS, or heavy libraries).

Double-click [index.html](file:///c:/harthika-portfolio/index.html) in Windows File Explorer.
